# ContactsApp-SwiftUI

A simple **SwiftUI MVVM** app for managing contacts.

---

## Features
- Clean MVVM architecture  
- SwiftUI + Combine  
- Localization ready  
- Unit test coverage  
- Dark Mode support  

---

## Tech
- Swift 6  
- iOS 18.0 
- Xcode 16
